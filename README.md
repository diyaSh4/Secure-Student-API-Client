\# Secure Student API \& Console Client



A secure student management system built with ASP.NET Core Web API and a C# Console Client.



\## Overview



This project demonstrates how to build a RESTful API for student management and consume it using a separate C# console application.



\## Technologies Used



\- C#

\- ASP.NET Core Web API

\- RESTful API

\- Authentication and Authorization

\- Layered Architecture

\- HTTP Client

\- In-Memory Data Storage (simulation)



\## Project Structure



\- \*\*API:\*\* Handles HTTP requests, business logic integration, and security.

\- \*\*Console Client:\*\* Communicates with the API.



\## Key Features



\- RESTful API endpoints for student management.

\- Authentication and authorization.

\- Separation of responsibilities through layered architecture.

\- A separate console client for API interaction.



\## Getting Started



1\. Clone this repository.

2\. Open the solution files in Visual Studio.

3\. Configure the database connection string.

4\. Configure authentication settings and required secrets securely.

5\. Run the API project.

6\. Update the Console Client's API base URL to match the running API.

7\. Run the Console Client.
